1. Introduction

SOCO-T1 is a three-phase Solar + Grid Automatic Changeover controller. It continuously and independently measures both a mains grid source and a solar source, drives external contactors to switch the load between the two sources based on user-configured voltage thresholds and time delays, and exposes all measured data over an isolated Modbus RTU (RS-485) link.

This manual describes installation, day-to-day operation, parameter configuration, and basic troubleshooting. For full electrical and environmental specifications, refer to the SOCO-T1 Product Datasheet. For the complete Modbus register list, refer to the SOCO Modbus Register Map.

2. Safety

WARNING — Hazardous Voltage. Voltage measurement inputs and the AC auxiliary input connect directly to mains potential. Installation and servicing must be performed only by qualified electrical personnel after isolating all sources.
CAUTION. Always de-energise both the grid and solar sources before opening the panel or working on terminals. Verify with a multimeter that no live voltage is present at the controller terminals.
CAUTION. Do not exceed the rated voltage (300 V L-N), CT secondary current, or relay contact ratings. Exceeding these limits will damage the controller and void the warranty.

5. Operation

5.1 Power-Up

On applying auxiliary power, the LED display briefly shows the firmware version, then begins cycling through measured parameters. The controller starts in Auto mode using the configured voltage thresholds and time delays.

5.2 Normal Display

The 6-digit LED display cycles through measured parameters automatically (or manually with the INC / DEC buttons). The pages shown include, for both Grid and Solar sources:

  • Phase voltages (Vr, Vy, Vb)
  • Phase currents (Ir, Iy, Ib)
  • Active, Reactive, Apparent power (per phase and total)
  • Power factor (per phase and total)
  • Frequency (per phase)
  • Energy import/export totals
  • Ambient temperature, Fan 1 / Fan 2 currents

5.3 Buttons

KeyNormal ModeEdit Mode
INCScroll forward through display pagesIncrement value
DECScroll backward through display pagesDecrement value
ENT(idle)Move to next parameter / accept value
INC + DEC (long-press ≈ 2.5 s)Enter Edit mode for parameter configuration

5.4 Entering Edit Mode

  1. Press and hold INC + DEC simultaneously for about 2.5 seconds.
  2. The display shows PASS and prompts for the password. Default password: 123 .
  3. Enter the password using INC / DEC ; confirm with ENT .
  4. The first editable parameter is shown. Use INC / DEC to change the value, then ENT to save and advance.
  5. After the last parameter, the controller returns to Normal mode automatically.
CAUTION. The password can be changed in Edit mode. Record any new password — there is no front-panel recovery procedure; a forgotten password requires factory intervention.

8. Switchover Logic

SOCO-T1 continuously evaluates the health of both sources and transfers the load using the rules below.

8.1 Health Definition

StateCondition
HealthyAll three phase voltages are between the Under-Voltage Reset and Over-Voltage Reset thresholds.
FailedAny phase voltage falls outside the Under-Voltage Trip or Over-Voltage Trip thresholds for longer than the Fail Delay.

8.2 Switchover Rules

EventAction
Grid healthyLoad is fed from Grid (Output 5 energised; Output 1/2/3 closed for grid path).
Grid fails — Solar healthyAfter Mains Fail Delay, controller transfers load to Solar (Output 4 energised).
Grid recovers (after a Grid fail)After Mains Return Delay, controller transfers load back to Grid.
Solar fails while on SolarAfter Solar Fail Delay, controller transfers load back to Grid (if Grid is healthy).
Solar recoversAfter Solar Return Delay (default 120 s) — intentionally longer to ensure stable solar generation.
Note: A short break-before-make safety gap is enforced on every transfer to prevent paralleling of the two sources.
